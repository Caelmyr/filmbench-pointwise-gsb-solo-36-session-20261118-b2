# FilmBench 彩色负片工作台

FilmBench 从一张扫描负片取样，将橙色片基下的各通道透射值映射成相对密度，再显影出可下载的正片。原始上传文件与原片坐标独立保留。

## 启动

```sh
docker compose up -d --build
```

打开 `http://127.0.0.1:18939/`。服务默认只绑定本机，容器数据保存在独立的 `filmbench-data` 卷。也可在 Python 3.11 或 3.12 环境中安装 `requirements.txt` 后运行 `python -B app.py`。本地进程默认写入 `data/`，可通过 `FILMBENCH_DATA_DIR`、`FILMBENCH_HOST`、`PORT` 调整。

## 操作

1. 点击“载入港湾日落”，或导入 PNG、JPEG、单页 TIFF。两份演示均为合成图，雨夜市集保留了已知位置的码值截断和灰尘。
2. 根据扫描文件来源选择 sRGB 或线性 RGB。使用“选透光片边”在完整原片中框出未曝光的胶片片基。未指定区域时，使用片边较亮样本的稳健初估，再用载入正片核对。
3. 调整显影的黑点、白点、曝光、对比或分通道偏置后应用。切换原片和正片同位对照、相对密度或扫描截断图。蓝色表示零值，橙红表示满量程，紫色表示同点有两类截断。
4. 框选画格，按需旋转、镜像。探针在完整原片上读取扫描码值和对应的正片颜色，右下放大像素周围的纹理。点修补在当前正片上操作：先点一块干净区域作为来源，再点要去掉的灰尘。修补采用频率分离，目标圆内保留灰尘周围原有的亮暗渐变，只从来源借用零均值的细颗粒，因此不会把来源底色盖成圆印；修补严格限制在半径圆内，贴着画格边的灰尘也不会把橙色片边带入或改动片边像素。
5. 从当前画格下载 8 位正片 PNG、16 位 RGB 正片 TIFF 或 16 位灰度相对密度 PNG。下载扫描原档会给出未修改的上传字节。导出的工程 ZIP 可在“恢复工程 ZIP”另建项目并重现当前设置。图像准备入口可单独运行通用帧处理和图像校正。

## 图像约定

- 接受 8 位或 16 位的无符号 RGB、灰度扫描。灰度会扩展为三个通道。最大 28 MB、有效像素 650 万，任一边长限 6500，短边至少 16。透明、别的色彩模型和多页 TIFF 需先在扫描软件中转换。使用输入设置解释颜色，不执行机身 RAW 解码或 ICC 颜色管理。按原生像素顺序读入，成片方向可在工作台调整。
- 片基和裁切坐标都在未转向的原片上，以左上为起点。点修补在正片画格上点击，服务端按当前裁切、转向和镜像换算成原片坐标存档，工程文件中的修补结构与历史版本完全同构。裁切、转向和镜像只作用于成片和同位对照。扫描截断诊断始终依据完整原档的码值。直方图可查看完整扫描的码值或当前画格显影后的线性值，大图使用规则采样计算直方图。
- 片基校准以线性透射率和所选区域中值为基础。密度使用相对片基的负对数，显示与下载把 0 至 1.6 单位映射为灰阶。正片输出以 sRGB 传递函数编码。结果是基于单一片基的数字显影，取样或扫描截断会影响颜色和能恢复的细节。
